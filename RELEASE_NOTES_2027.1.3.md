## EN

Windows saves are protected by document identity and edit generation; edits arriving during I/O stay dirty and reschedule in LIVE. Alerts, preferences and module availability no longer create false mobile patch revisions.

On conflict, Reload offers **Save copy then reload**, **Reload without copy** or **Cancel**. The copy uses a new unused location, preserves the local patch and suite resources/domains, and neither changes the shared project nor adopts the copy. Cancelling or failing the copy never reloads. Explicit reload stops transports; reconnect voluntarily. An invalid source project or occupied destination may prevent copying; local edits remain available.

Help > Diagnostics previews a voluntary JSON export on Windows and Mac. No automatic transmission, tokens, pairing/license codes, private keys, show paths, patch content or raw logs. External audio and projection are honestly reported as unobserved. Mac About shows source version 2027.1.3, build date, OS/architecture, silemio.com and manual access. Guide opens the StageFlow product manual; the suite guide remains separate.

StageFlow stays free, offline and optional. No new hardware connector, StageFlow participant or license contract. Approved PDFs are unchanged. Public release 2027.1.3 has been published since 2 October 2026 (metadata reread on 7 October, draft=false). Publication does not prove installation or physical Mac qualification.
