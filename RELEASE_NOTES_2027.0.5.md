# StageFlow v2027.0.5 - Windows

StageFlow reste gratuit, facultatif et autonome. Cette corrective améliore la
lisibilité de l'interface principale et du connecteur AutoCAD.

## Ce qui change

- Le bandeau Connexion, alertes, thème, langue, Guide et Aide est explicitement
  ancré à droite, quelle que soit la longueur du nom du show.
- La palette AutoCAD affiche réellement la liste des paires au lieu de la
  réduire à une ligne, même lorsqu'elle est étroite.
- La liste AutoCAD indique le numéro, le label ou la source, le micro, le groupe
  et l'état de chaque paire. La recherche et les filtres restent accessibles.
- Une paire peut être sélectionnée puis placée ; un double-clic déclenche la
  même commande de placement. Le point de pose reste toujours explicite.
- Les commandes de liaison, origine, calque, ensemble, exclusion et export
  restent visibles dans une palette courte.

## Compatibilité

Le format `.stageflow` et les domaines des autres logiciels ne changent pas.
Le connecteur reste facultatif et destiné à AutoCAD 2026 sous Windows. Cette
livraison Windows ne modifie pas le paquet macOS 2027.0.4.

# StageFlow v2027.0.5 - Windows

StageFlow remains free, optional and standalone. This corrective release makes
the main interface and the AutoCAD connector easier to read.

## Changes

- Connection, alerts, theme, language, Guide and Help are explicitly anchored
  to the right, regardless of the show name length.
- The AutoCAD palette now displays the actual pair list instead of collapsing
  it to a single line, including in a narrow docked palette.
- The list shows pair number, label or source, microphone, group and state.
  Search and filters remain available.
- Select a pair and use Place, or double-click it, to start the same placement
  command. The insertion point always remains an explicit user action.
- Link, origin, layer, named set, exclusion and export commands remain visible
  in a short palette.

## Compatibility

The `.stageflow` format and other applications' domains are unchanged. The
optional connector remains intended for AutoCAD 2026 on Windows. This Windows
release does not modify the macOS 2027.0.4 package.
